# Code Of Conduct

Ai-Memory-Free welcomes practical, respectful collaboration.

Contributors and maintainers must:

- discuss ideas and code without personal attacks or harassment
- give specific, evidence-based technical feedback
- respect different experience levels, backgrounds, identities, and viewpoints
- avoid publishing another person's private information or credentials
- disclose conflicts of interest that materially affect a recommendation
- keep security reports private until a fix is available

Unacceptable behavior may result in comments, issues, pull requests, or access being
removed. Report conduct concerns privately through
[KristianPeter.com/contact](https://kristianpeter.com/contact). Security
vulnerabilities should follow [SECURITY.md](SECURITY.md), not the conduct channel.
