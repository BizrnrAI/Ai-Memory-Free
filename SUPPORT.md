# Support

Ai-Memory-Free is free open-source software and does not include a paid support plan
or service-level agreement.

Use these paths:

- Installation: [INSTALL_WITH_AI.md](INSTALL_WITH_AI.md)
- Documentation map: [docs/INDEX.md](docs/INDEX.md)
- Common questions: [docs/FAQ.md](docs/FAQ.md)
- Reproducible bug: open a GitHub bug report with synthetic data
- Feature idea: open a GitHub feature request and explain the no-cost use case
- Vulnerability: use the private process in [SECURITY.md](SECURITY.md)

Before asking for help, run `npm run check`, remove all credentials from output, and
include versions for Node, Deno, Supabase CLI, operating system, and the relevant
commit.
